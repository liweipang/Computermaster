RSA Web Application (CBER-704 Project)

Enter RSA parameters p, q, e. Then enter either a numeric plaintext or a text plaintext. The system will display RSA key generation, encryption, decryption, and verification steps.

RSA Parameters

Requirement: p must be prime and p ≠ q.
Requirement: q must be prime and p ≠ q.
Requirement: 1 < e < φ(n) and gcd(e, φ(n)) = 1.

Plaintext Input

Requirement: 0 < m < n.
Note: Text mode converts each character to a numeric code before RSA encryption.
To avoid ambiguity, only one plaintext mode can be used at a time. When text plaintext is entered, numeric plaintext is disabled (and vice versa).

Output

The output is shown in a step-by-step format for RSA computation, encryption, decryption, and verification.
